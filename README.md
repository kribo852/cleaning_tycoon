# CleaningTycoon

## Description
A textbased tycoon game where you run a cleaning firm. You employ people, select different types of cleaning missions.


## Run the application
mix run -e 'CleaningTycoon.Terminal.start()'

This starts the genserver and then the terminal application on the same virtual machine.
